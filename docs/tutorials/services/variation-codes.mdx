# Variation codes API
 This section contains the recommended flow for getting variation codes for products that have variations on the VTpass RESTful API.
Variation code are available for some products that have multiple options like different data plans, different bouquets for CableTV etc.
This section shows how to get variation codes in a generic form even though you can find something similar on the individual.

:::info

Make sure you have done the following: [integrate with VTpass API](/docs/tutorials/getting-started/integrate-with-vtpass-api), [API key authentication](/docs/tutorials/getting-started/create-api-key), and [Whitelist products](/docs/tutorials/getting-started/whitelist-products)

:::

## Get variation codes
<Tabs>
  <TabItem value="curl" label="Curl" default>
   ```js
  curl --request GET \
  --url "https://sandbox.vtpass.com/api/service-variations?serviceID=gotv" \
  --header "api-key: YOUR_API_KEY" \
  --header "public-key: YOUR_PUBLIC_KEY"
   ```
  </TabItem>
  <TabItem value="js" label="Javascript">
    ```js showLineNumbers
    const BASE_URL = "https://sandbox.vtpass.com/api"; // Switch to https://vtpass.com/api for live

async function getServiceVariations(serviceID = "gotv") {
  const url = `${BASE_URL}/service-variations?serviceID=${encodeURIComponent(serviceID)}`;

  const response = await fetch(url, {
    method: "GET",
    headers: {
      "api-key": "YOUR_API_KEY",
      "public-key": "YOUR_PUBLIC_KEY",
    },
  });

  if (!response.ok) {
    throw new Error(`HTTP error: ${response.status} ${response.statusText}`);
  }

  const data = await response.json();

  if (data.response_description === "000" && data.content?.variations) {
    return data.content; // Returns { ServiceName, serviceID, convinience_fee, variations }
  } else {
    throw new Error(`VTpass API error: ${JSON.stringify(data)}`);
  }
}

getServiceVariations("gotv")
  .then((content) => {
    console.log(`Service: ${content.ServiceName}`);
    // Map plans for a dropdown or purchase payload
    const plans = content.variations.map((v) => ({
      code: v.variation_code,
      label: v.name,
      price: Number(v.variation_amount),
      isFixed: v.fixedPrice === "Yes",
    }));
    console.log("Available Variations:", plans);
  })
  .catch((err) => console.error(err));
    ```
  </TabItem>
</Tabs>

The following table describes the query parameter:

| Field | Required | Type | Description |
| :--- | :--- | :--- | :--- |
| `serviceID` | Yes | `string` | Change service ID to get variation codes for product/service |

### Expected response
```json
{  
   "response_description":"000",
   "content": {
      "ServiceName":"GOTV Payment",
      "serviceID":"gotv",
      "convinience_fee":"100 %",
      "variations":[  
         {  
            "variation_code":"gotv-lite",
            "name":"GOtv Lite N400",
            "variation_amount":"400.00",
            "fixedPrice":"Yes"
         },
         {  
            "variation_code":"gotv-value",
            "name":"GOtv value N1250",
            "variation_amount":"1250.00",
            "fixedPrice":"Yes"
         },
         ...
      ],
   }
}
```

### Response fields

The following table describes the response fields:

| Field | Type | Description |
| :--- | :--- | :--- |
| `response_description` | `string` | Response code. `000` means the request succeeded |
| `content.ServiceName` | `string` | Display name of the service |
| `content.serviceID` | `string` | Service ID you requested |
| `content.convinience_fee` | `string` | Convenience fee charged for the service. The key is spelled `convinience_fee` in the API |
| `content.variations` | `array` | List of variations available for the service |
| `content.variations[].variation_code` | `string` | Variation code. Send it in your purchase request to choose this plan |
| `content.variations[].name` | `string` | Display name of the variation |
| `content.variations[].variation_amount` | `string` | Price of the variation in naira |
| `content.variations[].fixedPrice` | `string` | `Yes` if the price is fixed, `No` if you can set the amount |
