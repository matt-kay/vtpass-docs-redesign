# Product options API
This section contains the recommended flow for getting product options for products that have options on the VTpass RESTful API.
Product options are available for some products that need extra details before purchase, such as passenger type or trip type for flight bookings.
Each product can have more than one option, so change the option `name` to get a different set of options for the same product or service.

:::info

Make sure you have done the following: [integrate with VTpass API](/docs/tutorials/getting-started/integrate-with-vtpass-api), [API key authentication](/docs/tutorials/getting-started/create-api-key), and [Whitelist products](/docs/tutorials/getting-started/whitelist-products)

:::

## Get product options
<Tabs>
  <TabItem value="curl" label="Curl" default>
   ```js
  curl --request GET \
  --url "https://sandbox.vtpass.com/api/options?serviceID=aero&name=passenger_type" \
  --header "api-key: YOUR_API_KEY" \
  --header "public-key: YOUR_PUBLIC_KEY"
   ```
  </TabItem>
  <TabItem value="js" label="Javascript">
    ```js showLineNumbers
    const BASE_URL = "https://sandbox.vtpass.com/api"; // Switch to https://vtpass.com/api for live

async function getProductOptions(serviceID = "aero", name = "passenger_type") {
  const params = new URLSearchParams({ serviceID, name });
  const url = `${BASE_URL}/options?${params.toString()}`;

  const response = await fetch(url, {
    method: "GET",
    headers: {
      "api-key": "YOUR_API_KEY",
      "public-key": "YOUR_PUBLIC_KEY",
    },
  });

  if (!response.ok) {
    throw new Error(`HTTP error: ${response.status} ${response.statusText}`);
  }

  const data = await response.json();

  if (data.response_description === "000" && data.content?.options) {
    return data.content; // Returns { ServiceName, serviceID, optionName, optionType, optionLabel, options }
  } else {
    throw new Error(`VTpass API error: ${JSON.stringify(data)}`);
  }
}

getProductOptions("aero", "passenger_type")
  .then((content) => {
    console.log(`${content.ServiceName}: ${content.optionLabel} (${content.optionType})`);
    // Map options for a dropdown or purchase payload
    const choices = Object.entries(content.options).map(([value, label]) => ({
      value,
      label,
    }));
    console.log("Available Options:", choices);
  })
  .catch((err) => console.error(err));
    ```
  </TabItem>
</Tabs>

The following table describes the query parameters:

| Field | Required | Type | Description |
| :--- | :--- | :--- | :--- |
| `serviceID` | Yes | `string` | Service ID as specified by VTpass. For example, `aero` |
| `name` | Yes | `string` | Option name as specified by VTpass. For example, `passenger_type` or `trip_type` |

### Expected response
```json
{
   "response_description":"000",
   "content": {
      "ServiceName":"Aero",
      "serviceID":"aero",
      "optionName":"passenger_type",
      "optionType":"MultipleSelect",
      "optionLabel":"Passenger Type",
      "options": {
         "adult":"Adult (18yrs and Above)",
         "child":"Child (3yrs to 19yrs)",
         "infant":"Infant (Below 3yrs)"
      }
   }
}
```

### Response fields

The following table describes the response fields:

| Field | Type | Description |
| :--- | :--- | :--- |
| `response_description` | `string` | Response code. `000` means the request succeeded |
| `content.ServiceName` | `string` | Display name of the service |
| `content.serviceID` | `string` | Service ID you requested |
| `content.optionName` | `string` | Option name you requested |
| `content.optionType` | `string` | How the options are presented, for example `MultipleSelect` |
| `content.optionLabel` | `string` | Human-readable label for the option |
| `content.options` | `object` | Map of option values to their display labels. Send the key (for example, `adult`) in your purchase request |
