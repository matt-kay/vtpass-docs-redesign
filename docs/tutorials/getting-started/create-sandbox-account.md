# Integrate with VTpass API
To connect to the API and go live it's recommended to start in the sandbox environment.

## Sandbox account
To create a sandbox account navigate to the [sandbox](https://sandbox.vtpass.com/register) portal.
After successfully registration, your account has a default wallet balance. Every transaction amount debits from the wallet balance.

Once you have a sandbox account proceed to [API key authentication](/docs/tutorials/getting-started/create-api-key)


## Sandbox API base URL
```js
https://sandbox.vtpass.com/api/
```

## Go live
When you have tested the API in sandbox environment and want to push to production, Read the [Go live and whitelist IP](/docs/how-to/go-live-and-whitelist-ip) guide.

## Support and technical assistance
You get integration support through multiple channels.

You can reach VTpass through email support@vtpass.com or connect on skype “vtpass.techsupport”. The tech support team assist.
