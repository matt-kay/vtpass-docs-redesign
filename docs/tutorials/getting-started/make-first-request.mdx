# Make your first request
You are awesome, for your first request lets query your VTpass wallet balance.
:::info

Before you start, [create a sandbox account](/docs/tutorials/getting-started/create-sandbox-account), [generate your API keys](/docs/tutorials/getting-started/generate-api-keys), and [whitelist the products](/docs/tutorials/getting-started/whitelist-products) you want to sell.

:::

## Get VTpass wallet balance request
<Tabs>
  <TabItem value="curl" label="Curl" default>
   ```js
   curl --request GET \
  --url https://sandbox.vtpass.com/api/balance \
  --header "api-key: YOUR_API_KEY" \
  --header "public-key: YOUR_PUBLIC_KEY"
   ```
  </TabItem>
  <TabItem value="js" label="Javascript">
    ```js showLineNumbers
    const url = "https://sandbox.vtpass.com/api/balance"; // Switch to https://vtpass.com/api/balance for live

async function getVtpassBalance() {
  const response = await fetch(url, {
    method: "GET",
    headers: {
      "api-key": "YOUR_API_KEY",
      "public-key": "YOUR_PUBLIC_KEY",
    },
  });

  if (!response.ok) {
    throw new Error(`VTpass API error: ${response.status} ${response.statusText}`);
  }

  const data = await response.json();
  return data;
}

getVtpassBalance()
  .then((data) => console.log("Wallet Balance:", data.contents?.balance))
  .catch((err) => console.error(err));
    ```
  </TabItem>
</Tabs>

### Expected response
```json
{
   "code":1,
   "contents":{
      "balance":1081.8199999998
   }
}
```

A `balance` value means your keys work and your account is ready. For every field, see [Wallet balance](/docs/reference/wallet-balance).
