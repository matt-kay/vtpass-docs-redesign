# Available services API
This section contains the recommended flow for getting the available service categories on VTpass RESTful API.
:::info

Make sure you have done the following: [integrate with VTpass API](/docs/tutorials/getting-started/integrate-with-vtpass-api), [API key authentication](/docs/tutorials/getting-started/create-api-key), and [Whitelist products](/docs/tutorials/getting-started/whitelist-products)

:::

## Get service categories
<Tabs>
  <TabItem value="curl" label="Curl" default>
   ```js
  curl --request GET \
  --url https://sandbox.vtpass.com/api/service-categories \
  --header "api-key: YOUR_API_KEY" \
  --header "public-key: YOUR_PUBLIC_KEY"
   ```
  </TabItem>
  <TabItem value="js" label="Javascript">
    ```js showLineNumbers
    const url = "https://sandbox.vtpass.com/api/service-categories"; // Use https://vtpass.com/api/service-categories for live

async function getServiceCategories() {
  const response = await fetch(url, {
    method: "GET",
    headers: {
      "api-key": "YOUR_API_KEY",
      "public-key": "YOUR_PUBLIC_KEY",
    },
  });

  if (!response.ok) {
    throw new Error(`HTTP error: ${response.status} ${response.statusText}`);
  }

  const data = await response.json();

  if (data.response_description === "000" && Array.isArray(data.content)) {
    return data.content; // Array of { identifier, name }
  } else {
    throw new Error(`VTpass API error: ${JSON.stringify(data)}`);
  }
}

getServiceCategories()
  .then((categories) => {
    console.log("Service Categories:", categories);
    // Example: extract identifiers to pass into /api/services?identifier=...
    const identifiers = categories.map((item) => item.identifier);
    console.log("Identifiers:", identifiers);
  })
  .catch((err) => console.error(err));
    ```
  </TabItem>
</Tabs>

### Response fields

The following table describes the response fields:

| Field | Type | Description |
| :--- | :--- | :--- |
| `response_description` | `string` | Response code. `000` means the request succeeded |
| `content` | `array` | List of available service categories |
| `content[].identifier` | `string` | Category identifier. Pass it as `identifier` to the [Services ID API](./services-id.mdx) |
| `content[].name` | `string` | Display name of the category |
